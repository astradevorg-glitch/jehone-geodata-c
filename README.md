# jehone-geodata-c

Part C of the Jehonë WDPA offline dataset. 138 chunks of `wdpa.pmtiles`, part0276 … part0413 (23 MiB each for GitHub's 25 MB web-upload limit).

See the manifest and app usage notes in [jehone-geodata-a](https://github.com/astradevorg-glitch/jehone-geodata-a).

Upload via the web: 138 files = 2 drags (100 + 38). Data © UNEP-WCMC and IUCN (WDPA).
